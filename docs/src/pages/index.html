Installation

The skill starts empty. Build your own palaces from scratch.

1

Clone the repository

git clone https://github.com/Algiras/memory-palace.git
2

Copy to skills directory

cp -r memory-palace/skills/memory-palace ~/.claude/skills/
3

Create your first palace

/memory-palace create "My Palace" "Ancient Library"
Storage location: ~/memory/ - Your palaces are stored locally in JSON format
