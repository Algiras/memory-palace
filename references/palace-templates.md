# Pre-Built Palace Templates

Ready-to-use palace structures for common use cases.

## The Ancient Library

**Best for**: Hierarchical knowledge, academic subjects, documentation

**Theme**: A vast, multi-story library with themed sections

### Structure
```
Entrance (Grand Hall)
├── History Wing (background/context)
├── Theory Section (core concepts)
│   ├── Fundamentals Alcove
│   ├── Advanced Theories Room
│   └── Edge Cases Corner
├── Practice Wing (how-to/tutorials)
│   ├── Beginner's Table
│   ├── Intermediate Shelves
│   └── Master's Archive
├── Reference Desk (quick lookups)
└── Rare Books Vault (advanced/specialized)
```

### Suggested Loci (15)
1. **Grand Entrance** - Overview/introduction
2. **Reception Desk** - Prerequisites, getting started
3. **History Wing Entrance** - Historical context
4. **History Reading Room** - Key developments
5. **Theory Section Door** - Core principles
6. **Fundamentals Alcove** - Basic concepts
7. **Central Theory Hall** - Main theories
8. **Advanced Theories Room** - Complex concepts
9. **Edge Cases Corner** - Exceptions, gotchas
10. **Practice Wing Door** - Practical application intro
11. **Beginner's Table** - Simple examples
12. **Intermediate Shelves** - Standard patterns
13. **Master's Archive** - Advanced techniques
14. **Reference Desk** - Quick reference items
15. **Rare Books Vault** - Specialized knowledge

### Anchor Objects
- Towering mahogany shelves
- Brass reading lamps
- Rolling ladders
- Leather-bound tomes
- Dusty scrolls
- A wise old librarian

## The Space Station

**Best for**: Technical concepts, systems architecture, programming

**Theme**: A modular space station orbiting a planet

### Structure
```
Airlock (entry point)
├── Command Bridge (system overview)
├── Engineering Deck (core mechanics)
│   ├── Power Core (fundamentals)
│   ├── Propulsion Bay (execution/runtime)
│   └── Maintenance Tunnels (debugging)
├── Science Lab (data/algorithms)
│   ├── Analysis Chamber
│   └── Experiment Pods
├── Communications Array (APIs/interfaces)
└── Cargo Hold (storage/data structures)
```

### Suggested Loci (12)
1. **Airlock** - Entry point, initialization
2. **Decontamination Chamber** - Validation, security
3. **Command Bridge** - Main control flow
4. **Navigation Console** - Routing, paths
5. **Engineering Deck** - Core implementation
6. **Power Core** - Fundamental operations
7. **Propulsion Bay** - Execution engine
8. **Maintenance Tunnels** - Error handling
9. **Science Lab** - Data processing
10. **Communications Array** - External interfaces
11. **Cargo Hold** - Data storage
12. **Escape Pods** - Fallbacks, recovery

### Anchor Objects
- Blinking control panels
- Floating in zero-gravity
- Humming machinery
- Viewport showing stars
- Robot assistants
- Warning klaxons

## The Journey Path

**Best for**: Sequential learning, processes, timelines

**Theme**: A winding path through varied landscapes

### Structure
```
Starting Village (prerequisites)
→ Forest Path (early concepts)
  → River Crossing (first challenge)
→ Mountain Climb (intermediate)
  → Cave System (deep concepts)
  → Summit (mastery point)
→ Valley Descent (application)
→ Destination City (expertise)
```

### Suggested Loci (10)
1. **Village Gate** - Starting point
2. **Village Square** - Prerequisites gathered
3. **Forest Entrance** - Beginning the journey
4. **Deep Forest** - Building knowledge
5. **River Bank** - First major challenge
6. **Bridge Crossing** - Overcoming obstacle
7. **Mountain Base** - Intermediate concepts
8. **Cave Entrance** - Deep/hidden knowledge
9. **Mountain Summit** - Key insight/mastery
10. **Destination City** - Full competence

### Anchor Objects
- Signposts with directions
- Fellow travelers
- Obstacles to overcome
- Treasures discovered
- Weather changes (mood)
- Landmarks visible ahead

## The Mansion

**Best for**: Broad topic coverage, comprehensive subjects

**Theme**: A grand Victorian mansion with many rooms

### Structure
```
Foyer (introduction)
├── Living Room (common use cases)
├── Kitchen (practical recipes/patterns)
├── Dining Room (combining elements)
├── Study (theory/documentation)
├── Bedroom (core/essential)
├── Bathroom (cleanup/maintenance)
├── Attic (advanced/obscure)
├── Basement (low-level/fundamentals)
└── Garden (external integrations)
```

### Suggested Loci (18)
1. **Front Porch** - First impressions
2. **Foyer** - Overview
3. **Coat Closet** - Setup/configuration
4. **Living Room** - Common patterns
5. **Fireplace** - Warmth/core comfort
6. **Kitchen** - Recipes/how-tos
7. **Pantry** - Ingredients/components
8. **Dining Room** - Combining elements
9. **Study** - Deep documentation
10. **Desk** - Working reference
11. **Library Shelf** - Extended reading
12. **Master Bedroom** - Essential concepts
13. **Closet** - Hidden features
14. **Bathroom** - Cleanup/refactoring
15. **Attic** - Advanced/legacy
16. **Basement** - Low-level details
17. **Garden** - External tools
18. **Shed** - Utilities

### Anchor Objects
- Antique furniture
- Family portraits
- Creaky floorboards
- Hidden passages
- Grandfather clock
- Mysterious butler

## Choosing a Template

| If your topic is... | Use... |
|---------------------|--------|
| Hierarchical/nested | Ancient Library |
| Technical/systems | Space Station |
| Sequential/process | Journey Path |
| Broad/comprehensive | Mansion |

## Customizing Templates

1. **Add loci** for more detail in important sections
2. **Remove loci** you don't need
3. **Rename** locations to match your domain
4. **Add children** to create sub-palaces
5. **Link** related loci across sections
