## Using These Examples

### As Templates
1. Copy the JSON structure
2. Replace the theme and content
3. Keep the loci structure that works
4. Add/remove loci as needed

### For Learning
1. Read through the vivid images
2. Notice the SMASHIN SCOPE techniques used
3. Observe how abstract concepts become concrete
4. See how linking creates knowledge graphs

### Key Patterns to Notice

| Pattern | Example | Why It Works |
|---------|---------|--------------|
| Wordplay | "Type" → physical stamp | Concrete substitute |
| Scale exaggeration | Giant lock | Memorable through absurdity |
| Interaction | You're serving the pie | Personal involvement |
| Sensory detail | Crystal you can see through | Multi-sensory encoding |
| Emotional hook | Terror at approach | Strong feeling = strong memory |

## Creating Your Own

1. Choose a [template](../references/palace-templates.md) that fits your topic
2. List the key concepts you need to memorize
3. Create the palace structure in JSON
4. For each concept, craft a vivid image using [techniques](../references/techniques.md)
5. Place images at specific loci
6. Add links between related concepts
7. Walk through your palace to test recall
